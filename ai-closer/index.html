Транскрипт этого звонка

Реактивация лида → запись на просмотр

Почему голос живой

«Человечность» — это настройки, зафиксированные на реальных тестах

⏸Паузы и выделение слов

Только теги <break 0.3–0.6s> — думающие паузы перед важным словом и перед вопросом. Ключевое слово: пауза до/после + CAPS. Имя — вперёд: «Райвис, добрый день».

💬Филлеры, пока думает LLM

Тихое «Мм / Угу / Ага» в паузе — бэкченел живого слушателя, тише основной речи, с задержкой, чтобы не ловить паузу клиента посреди мысли.

🏢Офисный фон

Room tone + клавиатура серверным миксом — идёт непрерывно, даже когда Алина молчит. Ducking, чтобы фон «нырял» под голос без синхронных скачков.

🎙Голос зафиксирован с клиентом

ElevenLabs Delia, живой звонок — eleven_multilingual_v2 (держит паузы, низкая задержка), записанные тизеры — eleven_v3 (максимум эмоций). Stability 0.6, style 0.40, speed 1.08 — «бодро, но не частит».

⚡Турн-тейкинг под русский

Чистый silence-таймер вместо ML smart-turn (мисфайрил на русском): VAD stop 0.3s + окно 0.2s — агент отвечает через ~полсекунды, не режет клиента посреди слова.

Как устроено

Свой код на Python + Pipecat — провайдер-агностик

Cascaded-пайплайн, а не «коробка» speech-to-speech: лучший отдельный TTS + контроль над скриптом + свобода менять любой «кубик» одной строкой конфига.

Внутри репозитория

Вся персона — это markdown-файлы и один конфиг

Смена ниши, продукта, скрипта, языка, голоса или «мозга» — без переписывания кода.

agent/ru-system-voice.md

Системный промпт: личность, правила человечной речи, методология продажи, гардрейлы.

agent/objection-playbook.md

Плейбук возражений: признать → выяснить настоящую причину → ответить → снова закрыть.

agent/ru-script.md

Каркас звонка: опенер (одобрен), квалификация, питч под боль, закрытие на демо.

config.yaml

Все «ручки»: персона, opening_line, LLM, STT, TTS-настройки живости, филлеры, фон, VAD.

Комплаенс: раскрытие ИИ, запись звонка, антиспам — отдельным документом (US/EU). Знания: агент говорит только факты из базы знаний — без выдуманных скидок и обещаний.
